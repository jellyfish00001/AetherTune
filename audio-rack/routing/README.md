# Routing profiles

Routing profile 記錄 capture input、backend output、rack input/output、virtual device、loopback input、sample rate、channel、buffer 與實際方向證據。

既有 Windows 路由仍以 `docs/architecture.md` 與 `docs/operation-guide.md` 為準；`seed-vc-virtual-route.json` 只登記已驗證的 synthetic route，不自動修改 Windows 音訊裝置，也不代表 physical mic E2E。
