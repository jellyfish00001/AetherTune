# Plugin profiles

每個 plugin profile 至少記錄：名稱、版本、VST2/VST3 format、來源 URL、license classification、sample rate、buffer/lookahead、bypass latency、active latency、Δ latency、artifact path 與狀態。

「免費」與「開源」分開記錄。Graillon、VB-CABLE、Voicemeeter 等現有元件不可因免費就標成 OSS。已登記的 Graillon profile 仍須補 Light Host loaded、bypass/active latency 與人工聽測證據。
