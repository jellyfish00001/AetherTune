# Speech reconstruction model cache

CosyVoice、Breeze TTS 2 與 STT 模型不進 Git，且必須分環境保存。建議：

```text
models/speech-reconstruction/cosyvoice/
models/speech-reconstruction/breeze-tts-2/
models/speech-reconstruction/stt/
```

Breeze TTS 2 的 self-hosted license 是 research/non-commercial；不得因為程式碼是 Apache-2.0 就把權重或輸出宣稱為 Apache 授權。
